# 🎮 AI Tic-Tac-Toe

A console-based Tic-Tac-Toe game developed in Python where the player competes against an AI opponent.

The AI uses the **Minimax algorithm** to analyze possible moves and make intelligent decisions during the game.

## 📌 Project Overview

This project was developed as part of my **CodeSoft Internship Task 2**.

The game allows a human player to play Tic-Tac-Toe against a computer-controlled opponent.

- Player: **X**
- Computer: **O**
- Board: **3 × 3**
- Input: Positions 1–9
- AI Algorithm: **Minimax**

## ✨ Features

- 🎮 Player vs AI gameplay
- 🤖 Intelligent AI opponent
- 🧠 Minimax algorithm
- ✅ Win detection
- 🤝 Draw detection
- 🚫 Invalid move detection
- 🔄 Prevents already occupied positions
- 💻 Simple console-based interface

## 🧠 How the AI Works

The computer uses the **Minimax algorithm** to evaluate possible moves.

The algorithm:

1. Checks whether the current board has a winner.
2. Checks whether the game is a draw.
3. Generates all available moves.
4. Simulates possible moves.
5. Evaluates the resulting game states.
6. Selects the best possible move for the computer.

This allows the AI to make strategic decisions instead of selecting moves randomly.
